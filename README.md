# Ecommerce Customer Behavior & Sales Performance Analysis

## Project Overview

This project analyzes customer purchasing behavior and sales performance using Python, Pandas, NumPy, Matplotlib, and Jupyter Notebook.

The analysis provides insights into customer trends, sales performance, top-selling categories, regions, and products.

## Objectives

- Understand customer purchase patterns
- Analyze sales trends over time
- Identify top-selling categories
- Discover high-performing regions
- Find best-selling products
- Generate business insights

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Files

- customer_behavior_analysis.ipynb
- sales_performance_analysis.ipynb
- README.md

## Key Findings

### Customer Behavior Analysis
- Identified customer purchase patterns
- Analyzed customer demographics
- Explored purchasing trends

### Sales Performance Analysis
- Total Revenue: 2,261,536.78
- Total Orders: 4,922
- Average Order Value: 459.48
- Top Category: Technology
- Top Region: West
- Top Product: Canon imageCLASS 2200 Advanced Copier
